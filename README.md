# JUGNU Mineral Water

GitHub-ready package for the JUGNU Mineral Water web app.

## Files
- `index.html` — main application (includes the WhatsApp share-image contrast and layout corrections)
- `manifest.webmanifest` — install metadata
- `icon-192.png` — app icon
- `sw.js` — service worker registration support

Upload all four files to the root of your GitHub Pages repository.

The app's existing IndexedDB data and backup/restore logic have been preserved. Keep a separate JSON backup before replacing an existing deployed version.
